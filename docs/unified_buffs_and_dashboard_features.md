## 2. 各プロンプトの実装内容詳細

### プロンプト1: バフ合算の内訳表示の全ステータス統一＆未表示効果の追加
- **回復固定値（`recoveryFlat`）の合算対応**:
  - `calculateBuffs()` の `buffs` 初期化に `recoveryFlat: { sum: 0, items: [] }` を追加。姫路城など回復固定値を持つ城娘のバフを正確に合算・格納。
- **未表示だった全ステータス行の追加**:
  - `防御(%)`（`defPercent`）、`防御固定`（`defFlat`）、`耐久(%)`（`hpPercent`）、`耐久固定`（`hpFlat`）、`回復固定`（`recoveryFlat`）の行を新設。
- **表示形式と内訳展開トグルの全行統一**:
  - すべてのバフ行（攻撃・防御・耐久・回復・射程・与ダメ・速度・隙・被ダメ・共有・防御無視）で、「合計値」「最大値採用か加算かの区別」「内訳▾」トグルを統一。
  - 内訳リストには `[最大値適用]`、`[加算]`、`[未適用]` を色分けして明示し、発動城娘・発動区分（特技/計略/特殊能力）・rawテキストを表示。
- **敵デバフ一覧の統一**:
  - 敵防御・敵攻撃・敵移動・敵被ダメの各行にも「最大値採用」「内訳▾」を実装し、競合して適用されていない効果（未適用）と採用効果がひと目で判別可能。

### プロンプト2: ダッシュボードから直接ステージ適合診断を開く機能
- **コントロールバーへの UI 追加**:
  - `.dashboard-control-bar` の出撃地形セレクト横に `<select id="dashboardStageSelect">` と `<button id="btnDashboardDiag">⚔️ 適合判定</button>` を配置。
- **optgroup による分類生成**:
  - `window.SCRE_GUIDES` の各カテゴリ（地獄、武神降臨、四季御殿、群雄割拠）を `<optgroup>`、各ステージ名を `<option>` として自動生成（地形属性タグ付き）。
- **出撃地形の自動連動**:
  - ステージを選択すると、そのステージの地形属性（地獄・平・山・水・平山）を出撃地形セレクトに自動反映し、全員の巨大化気計算や地形一致ボーナスをリアルタイム再計算・保存。
- **ダイレクト診断呼び出し**:
  - 「⚔️ 適合判定」ボタンを押すと、既存の `openStageDiagnostic(stageTitle)` がそのまま呼び出され、部隊の適合判定モーダルが即座に起動。

### プロンプト3: 現在の編成を名前リストで書き出す機能
- **書き出しボタンの追加**:
  - 「名前でまとめて読み込み」セクションに `<button id="btnExportPartyNames">現在の編成を書き出す</button>` を新設。
- **双方向の可逆読み書き**:
  - クリックすると、現在アクティブなプリセットの8体の城娘名をカンマ区切りテキスト（例: `姫路城, 崑崙, 小早川城, ［漆磊］広島城, ［無疆］江戸城, ［球陽］首里城, ［お月見］鹿野城, 逸見エリカ`）として入力ボックスに展開。
  - 同時に `navigator.clipboard.writeText()` でクリップボードに自動コピーし、ボタンに「✓ コピーしました」とフィードバック表示。
  - 書き出したテキストをそのまま「反映」ボタンで読み込むと、全く同じ順序・同じ8体が完全に復元されることを検証済み。編成が空の場合は「編成が空です」と安全に通知。
