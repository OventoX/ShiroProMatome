# 城プロRE 編成・バフ/デバフ統合ダッシュボード & 高難易度攻略シミュレータ

『御城プロジェクト:RE（城プロRE）』の8人部隊編成、特技・計略・特殊能力によるリアルタイムなステータス合算、バフ・効果の逆引き検索、および地獄（ハデス・閻魔・ヘル・オシリス）・武神降臨などの高難易度マップ適合判定を行う統合Webアプリケーションです。

Node.jsやPython等のWebサーバーを立てる必要がなく、**ローカルの `app/index.html` をブラウザで開くだけで100%完全オフラインで動作**します。

---

## 🌟 主な機能

### 1. 8人部隊編成 ＆ リアルタイム・バフ/デバフ合算エンジン
- **全ステータス完全合算**:
  - 攻撃（% / 固定値）、防御（% / 固定値）、耐久（% / 固定値）、回復（固定値）、射程（% / 固定値）、与ダメージ（%）、与えるダメージ（%）、攻撃速度（%）、隙短縮（%）、被ダメージ軽減（%）、ステータス共有（鼓舞）、防御無視を網羅。
  - 特技・計略（ON/OFF）・特殊能力（ON/OFF）の切り替えに応じた瞬時再計算。
- **統一された内訳表示トグル（`内訳▾`）**:
  - 各バフ行で「合計値」と「最大値採用 / 加算合計」のルールを明示。
  - トグル展開により、各発生源（城娘名・特技/計略/特殊・rawテキスト）ごとに `[最大値適用]`、`[加算]`、`[未適用]` を色分けして確認可能。
- **敵デバフ最大値採用判定**:
  - 敵防御低下、敵攻撃低下、敵移動低下、敵被ダメージ上昇の重複を判定し、実効最大値を自動算出。

### 2. 1,161体 全城娘データベース ＆ 複合属性・逆引き検索
- **城娘詳細モーダル**:
  - 全身高画質イラスト（S.png）、図鑑文章、絵師・声優・地域情報、初期配置〜改壱・改弐のステータス推移、発動バフタグ一覧を表示。
- **複合属性対応（240体以上）**:
  - 平/山、平/水、水/地獄などのハイブリッド属性をスプリットグラデーションバッジで可視化。属性フィルタでは両属性に完全マッチ。
- **バフ・効果カテゴリによる逆引き検索**:
  - 「攻撃固定値バフ持ち」「足止め持ち」「敵防御低下持ち」「被ダメ軽減持ち」など、部隊に足りない効果を持つ城娘を一発抽出。

### 3. 地形一致シミュレーション ＆ 総消費気エンジン
- **出撃地形の指定**:
  - 平・平山・山・水・地獄を選択すると、地形一致城娘に合戦ステータス1.25倍および巨大化消費気35%軽減を自動適用。
- **総消費気の自動計算**:
  - 部隊全員の初期配置気＋最大巨大化（5回）に必要な実効総消費気をリアルタイム算出。

### 4. 高難易度マップ攻略 ＆ 部隊適合判定（全182ステージ収録）
- **ハデスの死闘場（超難・全11深層マップ完全網羅）**:
  - 各20項目・最大36審議、マップ特別ルール、ボス特性、ハデスの霊魂自爆（暗闇＋計略気+2）、再配置時間50秒・気30固定を完全収録。
  - 赤霊魂（閻魔大王/イザナギ/覇・前田利家/クロノス）、青霊魂（ヘル/オーディン/幻・佐竹義重/ヴィシュヌ）、黄霊魂（オシリス/インドラ/アヌ）の深層体系に対応。
- **地獄・武神降臨・四季御殿・群雄割拠**:
  - 閻魔の闘技場（42層）、ヘルの遊戯場（38層）、オシリスの審判場（39層）、歴代武将兜降臨（20ステージ）、四季御殿（22回廊）、群雄割拠（10絵巻）。
- **ダッシュボードからの直接適合判定 ＆ 地形自動同期**:
  - ダッシュボード上部のステージ選択セレクトから、現在編成の適合性を1クリックで判定可能。
  - ステージ選択時にそのステージの出撃地形が自動設定され、巨大化気・ステータスが即座に連動。
  - ハデス死闘場診断では、地獄地形一致率、暗闇・状態異常対策（回復/無効持ちの有無）、配置制限審議（平/水/山/地獄等の上限超過）、近接/遠隔与ダメ99%低下への抵触を自動警告。

### 5. プリセット管理 ＆ ワンクリック画像出力 ＆ 可逆名前書き出し
- **プリセット1〜5**:
  - 平パ、山パ、水パ、地獄審議パなど用途別に5枠保存・名前変更・ワンクリック切り替え。
- **名前リストによる可逆入出力**:
  - 現在の編成城娘名をカンマ区切りテキストとして書き出し＆クリップボードコピー（「現在の編成を書き出す」）。
  - 書き出したテキストをそのまま「反映」ボタンで読み込むと、同じ8体・同じ順序を完全復元。
- **Twitter/X共有用 高画質サマリー画像（1200x675 PNG）**:
  - 部隊8体のアイコン、実効ステータス、バフ網羅チェックリストを1枚の美しいサマリー画像として書き出し保存。

### 6. Wiki差分自動更新ルーティン
- 毎週金曜の定期メンテナンス後に `update_weekly.bat` を実行することで、Wikiの「RecentChanges」から直近更新されたページのみを自動取得し、城娘データおよび攻略データを最新化。

## 🚀 使い方

### 1. アプリの起動
特別なサーバー起動コマンドは不要です。
ブラウザ（Google Chrome, Edge 等）で以下を開くだけで起動します。

```
app/index.html
```

### 2. E2E 自動テストの実行
Puppeteer を用いた全17項目のブラウザ自動回帰テストが同梱されています。

```powershell
cd tools
npm install
node test_e2e.js
```

### 3. Wikiデータの最新化
新しい城娘や新ステージがゲーム内に追加された場合、以下のバッチを実行するだけで差分取得・再コンパイルが完了します。

```powershell
.\update_weekly.bat
```
