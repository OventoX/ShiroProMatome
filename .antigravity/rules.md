# プロジェクト運用ルール (ShiroProMatome / scre-helper)

本プロジェクト（城プロRE 編成・バフ/デバフ統合ダッシュボード & 攻略シミュレータ）での実装・改修作業時は、以下の運用ルールを遵守すること。

## 1. 成果物の GitHub 自動同期
- 新機能の実装、バグ修正、データ更新、ドキュメント追加などの作業が完了した際は、**必ずローカルの変更を Git にコミットし、リモートリポジトリ（`origin/main` - `https://github.com/OventoX/ShiroProMatome.git`）へ自動プッシュ**すること。
- コミットメッセージはConventional Commits（`feat:`, `fix:`, `docs:`, `test:`, `data:` など）に準拠し、分かりやすい日本語要約を付与すること。

## 2. 実装前後の品質検証
- UIや計算ロジックに変更を加えた場合は、必ず E2E テスト（`node tools/test_e2e.js`）を実行し、全テスト項目（17+項目）がPASSすることを確認してからコミットすること。
- スタンドアロン動作（Node.jsサーバー不要の `file://` / 静的ホスティング完全対応）を維持すること。

## 3. ドキュメントと仕様の最新化
- 仕様変更や高難易度マップ（地獄・ハデス・武神降臨）データの追加時は、`README.md` および `docs/` 配下の解説ドキュメントを同期して更新すること。
